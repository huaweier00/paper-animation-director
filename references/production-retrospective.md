# 制作复盘：从纸影项目提炼的导演规则

这份文档把一次完整的横版纸片动画项目复盘成可迁移的制作方法。它不是某个故事的美术设定，而是用来避免“画面漂亮但空间不成立、台词说了但画面没证明、人物动了却像贴纸顺移”的工作规程。

## 0. 一句话原则

**先让世界成立，再让素材成立；先让动作可读，再让动作好看；先让声音归属正确，再谈声音有多好听。**

纸片动画的高级感不来自零件数量，而来自以下四件事同时可信：

1. 角色是谁、比例是否稳定；
2. 他站在哪里、能不能真的走到那里；
3. 他碰到了什么、力如何传过去；
4. 观众即使关掉声音，也能看懂发生了什么。

## 1. 复盘样本与适用范围

本规程来自一个 1920×1080 横版中国历史题材纸影项目的制作复盘。项目经历了：旧镜头诊断、横版重构、汉代空间考据、完整人物资产继承、整场景多帧、连续舞蹈帧、规范化步态、皮影制作流程展示、角色配音候选、字幕与混音校对，以及逐镜 HyperFrames 检查。

它最适合以下任务：

- 有连续剧情和重复角色的剪纸、纸影、宣纸水彩动画；
- 需要历史、民俗、非遗或建筑形制可信度的宣传片；
- 画面由完整角色帧、场景板、灯光、帷幕和道具组成的 2D 分层动画；
- 台词、旁白、角色对白和字幕需要精确互相对应的叙事视频。

它不替代 HyperFrames、imagegen、media-use 或动态水印 skill，而是规定这些工具在纸片动画中的先后顺序和验收标准。

## 2. 项目总流程：八道门

```mermaid
flowchart LR
  A[剧本与历史证据] --> B[空间圣经]
  B --> C[角色/道具资产决策]
  C --> D[最难镜头 8–15 秒基准]
  D --> E[完整姿势与接触帧]
  E --> F[配音/字幕/时间轴]
  F --> G[静音证明与 HyperFrames 检查]
  G --> H[渲染帧审查与交付]
  G -.失败.-> B
  G -.动作不清.-> D
```

每道门都要留下可检查的文件或结论，不要只在对话里“记住”：

| 门 | 必须留下 | 未通过时怎么做 |
| --- | --- | --- |
| 1. 故事 | `story-manifest.json`、事件链、旁白归属 | 重写因果，不生成素材 |
| 2. 历史 | 采用清单、排除清单、来源链接 | 改 prompt 与空间，不用“泛古风”补救 |
| 3. 空间 | 俯视平面、正视机位、深度轴、人物路径 | 重画背景，停止角色生成 |
| 4. 资产 | 身份图、完整姿势表、整场景/ensemble 决策 | 拒收不合适素材，不为复用而复用 |
| 5. 基准 | 最难动作的 8–15 秒 proof composition | 只修基准，不批量扩展 |
| 6. 声音 | 试音表、实测时长、角色归属、混音窗口 | 重生成或延长画面，不强压语速 |
| 7. 审片 | 静音证明帧、字幕安全区、接触检查、CLI 结果 | 回到对应门修问题 |
| 8. 交付 | MP4 抽帧、FFprobe、master/social 报告 | 不把 Studio 预览当成成片证据 |

## 3. 剧本先变成可见事件

### 3.1 把台词拆成“谁说、看见什么、发生什么”

每句旁白或对白都写成：

```text
说话者 → 台词意图 → 可见动作 → 空间/道具变化 → 反应 → proof frame
```

例如：

```text
李夫人 → 主动拒绝见帝 → 撑床坐起、按住被角 → 帐内光线收暗 → 姐妹垂首 →
静音仍能看出她清醒选择“不见”
```

### 3.2 台词不能替画面完成动作

如果旁白说“揭下榜文”，画面必须有榜文被扯下、离开墙面、进入人物控制范围的过程；如果说“直到咽气，她都没有掀开被子”，这句话必须归旁白，不能让夫人或宫女误念，也不能在同一时间窗重叠播放。

如果动作只能靠声音解释，场景在 P0 语义门就失败。台词可以补充因果，但不能替代因果。

### 3.3 情绪要服从人物关系

- 美好回忆中的宫人不能无理由愁眉苦脸、哭泣或出现夸张鼻涕泪滴；
- 面对皇帝的李夫人应是虚弱、清醒、带主动选择，不是春光满面，也不是只会哭；
- 面对皇帝的方士应体现跪地、抬头、谨慎进言的礼制；
- 皇帝的激动应通过起身、转向、步幅、停步和声音压迫感完成，不用现代握手礼；
- 工艺镜头中的工匠要有从紧绷/愁苦到克制欣慰的表情阶段，不能从头到尾一张脸。

## 4. 历史考据：采用清单与排除清单必须成对出现

### 4.1 先确定证据等级

历史图像不是“搜一张古装图”。把参考分为三类：

1. **结构证据**：建筑明器、遗址、出土构件、博物馆藏品，用来决定柱网、台基、门窗、地面和尺度关系；
2. **活动证据**：画像石、陶俑、文献、礼制资料，用来决定席地、宴饮、跪拜、奏乐和表演位置；
3. **材质证据**：漆木、夯土、方砖、条砖、帷帐、油灯、丝帛，用来决定表面和光泽。

明器和画像是形制证据，不是可以逐比例照抄的施工图；每条来源都要写“本片采用什么、明确不采用什么”。

### 4.2 汉代空间的可复用约束

- 宫殿的庄重首先来自高台、轴线、柱网、开间、台阶和维护状态，不靠金色、红灯笼或巨大屋顶；
- 高等级殿堂可使用深灰褐/赭黑的密缝方砖、条砖和哑光烧制表面；不要画成现代抛光瓷砖、粗石板或破败遗址；
- 席地、低榻、低案、帷帐和灯位要有真实落点；不能出现悬空桌案、漂浮烛台或没有支撑的帐杆；
- 汉代表演首先发生在厅堂、殿庭、广场或临时棚架，不自动套用后世固定镜框戏台；
- 宫门、便殿、寝殿、作坊、民间棚架要按功能区分，不能用一张“古代大厅”打全片；
- 西汉与唐宋、明清的屋顶、斗栱、御座、戏台、灯笼和色彩秩序必须有排除说明。

### 4.3 历史 prompt 最低要求

每次生成背景前，prompt 至少回答：

```text
这是哪个时代、哪个功能空间？
它由哪些结构证明？
人物在哪里坐、跪、走、停？
光源在哪里，是否可独立控制？
哪些后世元素禁止出现？
哪些区域必须留给动作和字幕？
```

## 5. 空间圣经：先俯视，再正视，再生成

### 5.1 每场必画的九个点

俯视平面至少标出：

1. 房间/舞台边界；
2. 门、柱网、台阶和墙；
3. 榻、席、低案、幕架或画廊壁；
4. 主光源与光学轴；
5. 每个角色的起点与终点；
6. 镜头位置和朝向；
7. 角色视线轴；
8. 前景遮挡与安全区；
9. 可走路径、不可穿越的物体和接触距离。

随后再画正视镜头，确认地面线、脚底线、物体高度和遮挡顺序。没有这两张图，不生成背景。

### 5.2 统一比例与基线

为每场选一个 `1.00H` 基准人物，记录站立高度、跪坐视觉高度、榻面、灯口、幕高、柱高和镜头高度。所有角色帧必须共享：

- 统一画布尺寸；
- 统一脚底基线；
- 统一人物中心；
- 统一透明留白策略；
- 统一光向与纸边处理。

人物大小不能靠 CSS 多次缩放“试出来”。先在资产阶段校准，再在世界坐标中移动。

### 5.3 视角选择规则

- 两个角色需要同时读脸、读姿态、读关系时，优先使用侧面或三分之四侧面；
- 角色从右向左走，就让头、肩、胸口、脚步和视线都朝向左，不能边接近边回头制造不可能的扭转；
- 皇帝、方士或舞者的空间等级，要通过站位、席位、台阶和镜头高度证明，不要把皇帝放在角落或蹲在画面边缘；
- 需要走路的角色不要和背景一体生成；需要精确接触的角色不要分别生成后强行碰撞；
- 视角一旦锁定，后续镜头只能改变焦距、裁切或景别，不能无提示地交换左右关系。

## 6. 资产决策：整场景、完整角色、独立物件三选一

### 6.1 决策表

| 画面单元 | 默认生成方式 | 为什么 |
| --- | --- | --- |
| 床 + 人物 + 被褥 + 帐内关系 | 整场景多帧 | 接触、透视、遮挡最难，拆开容易悬空 |
| 灯体 + 灯盘 + 火焰 | 一体资产 | 火焰来源、光池、落点必须统一 |
| 需要走路的皇帝/方士 | 独立完整角色多帧 | 需要移动、换步、停步和反应 |
| 精确扶起、拦驾、抬物、拥抱 | 连体 ensemble 多帧 | 手、肩、负重和接触不能靠猜 |
| 舞者长袖 | 角色完整帧 + 必要袖带跟随层 | 身体身份稳定，软体运动可滞后 |
| 帐纱、烟、火光、纸纹 | 独立效果层 | 有独立物理责任，但不应承载角色语义 |
| 影人展示工艺 | 完整影人画面帧 | 观众要看懂成品比例和制作流程 |

### 6.2 “独立”不等于“拆零件”

独立角色是完整的头、躯干、手、袖、腿和鞋在同一张透明图中；独立灯是完整的灯和火焰在同一张图中；独立场景是床、人物、被褥、帐架一起生成。只有需要独立运动的物件才拆出，不能把“可分层”误解成“把人体拆开”。

### 6.3 适配优先于复用

资产继承顺序是：

```text
适合当前空间/比例/动作的既有资产
  > 重新生成适配资产
  > 为了复用而硬套既有资产
```

如果角色面向、比例、服装、空间深度或光向不合适，宁可重新生成。项目经验表明，强行复用会引发更高成本的修补：漂浮桌案、皇帝站错位置、方士朝向奇怪、人物头大身小、背景与人物像两张贴纸。

## 7. 角色一致性与帧系统

### 7.1 身份锁定卡

每个重复角色保存一张身份卡：年龄、脸型、眉眼、发式、帽冠、服装轮廓、腰带、鞋、主色、纸边颜色、禁用变化。每一张新图都以身份参考图为条件，不凭记忆重新描述。

### 7.2 走路必须是步态，不是顺移

最小步态循环建议六帧：

```text
承重 → 抬脚 → 落脚 → 过渡 → 换脚 → 收势
```

生成阶段统一画布、人物中心和脚底线；动画阶段只做父轨道的世界位移，子帧按固定节拍硬切。不要用三个 `power1.inOut` 平移段加淡化模拟走路，也不要在角色方向不一致时靠旋转补救。

每个步态检查：支撑脚是否真的承重、衣摆是否有滞后、头肩是否与移动方向一致、脚底是否跳线、镜头是否把人物比例放大/缩小成不同角色。

### 7.3 表情是状态帧，不是滤镜

悲伤、专注、释然、惊喜、威压、欣慰必须通过完整脸部和身体状态帧表达。不要用统一的阴影、红晕、泪滴或缩放滤镜代替角色心理变化。

## 8. 动作导演：因果、接触、传播、结果

### 8.1 每个重点动作要写四种关系

```text
因果：为什么动？
接触：谁碰到了什么？
传播：力、光、烟、影子或水如何传过去？
结果：状态具体改变了什么？
```

例如灯影关系：

```text
灯亮 → 完整影人靠近白幕 → 光池扩大、影缘变清 → 舞姿被识别
帐纱掠过 → 影人离幕/纱改变光路 → 影子变软、放大 → “近则散”被看懂
```

### 8.2 接触动作优先 ensemble

扶起、拦驾、握持、抬桌、拉绳、传桶、拥抱、共同负重等动作，优先生成包含所有参与者和共享物体的整体帧。单人 PNG 在时间线上“碰到一起”不等于接触成立，尤其会造成现代握手、手臂穿模、肩膀错位和负重无反馈。

### 8.3 多帧不是越多越好，而是要覆盖状态变化

一段舞蹈至少需要起势、展开、转折、回旋、定势；一段工艺流程至少需要材料、操作接触、结果、下一工序；一段走路至少需要完整步态周期。帧数由可见状态变化决定，不以“零件数量”或“生成了几张图”作为指标。

## 9. 声音、台词与字幕

### 9.1 角色归属先于混音

给每句台词写 `speaker` 字段并单独挂载：旁白、宫女、李夫人、方士、皇帝不能共享一个模糊的“对白轨”。出现以下情况必须停下来修正：

- 旁白替角色念了角色的第一人称句；
- 角色台词和旁白同一句重叠；
- 一句台词被相邻角色误念；
- 为赶画面强行压快关键情绪；
- 等待时间过长，人物已经开口但声音还没进来。

### 9.2 音色筛选加入“口音排除”

候选试听不只比较“好听”：还要检查普通话/方言、咬字、句尾、年龄、身份感、情绪范围和与其他角色的区分度。历史人物对白优先选明确标注 Mandarin / Mandarin Chinese、clear、professional、documentary 或同等证据的音色；发现方言立即停用，不因已经生成而迁就。

### 9.3 画面给声音留空间

用实测音频长度倒推画面节拍。情绪台词宁可多留 0.2–1.0 秒，也不要把夫人的哀叹、帝王质问和旁白压成急促口播。画面复杂而旁白快时，优先增加内部动作或延长场景，不能用全局加速掩盖画面对不上。

### 9.4 字幕安全区

- 默认底部水平居中；不要左对齐到画面边缘；
- 字幕不遮挡手、被角、脚底、灯座、影子边缘和关键接触点；
- 竖排书法只在叙事明确需要时使用，并检查左右列是否被前景或边界裁切；
- 每条字幕有进入、可读、退出窗口，不能靠相邻交叉淡化造成重复阅读；
- 画面出现多个角色时，字幕仍要让观众知道谁在说话，必要时使用声部/角色标记而不是把字堆在人物脸上。

## 10. 证明与审片

### 10.1 三次观看法

1. **静音看**：能否看懂谁、在哪里、做了什么、结果是什么？
2. **只听声音**：每句是谁说的？是否有重叠、抢词、方言、错误情绪？
3. **画音合看**：动作、字幕、台词、光和转场是否在同一语义节拍上？

### 10.2 每镜必须抽查的帧

- 第一帧：空间是否已建立，角色有没有被裁掉；
- 起因帧：事件为什么开始；
- 接触帧：手、肩、物体、幕、灯是否真的接触；
- 传播帧：力、光、影、烟、水是否按方向传递；
- proof frame：静音仍可读；
- 转场前后帧：人物左右关系和地面基线是否连续；
- final-minus-hold：最后动作是否已经完成；
- 最后一帧：字幕、灯光、角色和尾签是否安全。

### 10.3 预览工具问题不等于内容通过

本地 `file://` 打不开、预览缓存旧版本、Studio 与渲染帧不一致时，先确认服务器、绝对/相对路径、素材存在和浏览器缓存，再继续审片。永远以渲染 MP4 抽帧和 FFprobe 作为交付证据，不把某一次 Studio 截图当成最终成片。

## 11. 失败模式速查

| 看到的症状 | 常见根因 | 立即修正 |
| --- | --- | --- |
| 皇帝像蹲在角落、椅子在身后却坐不上 | 先复用角色/家具，后想空间 | 删除不必要家具，先画侧视平面和行走路径 |
| 桌子像悬在空中 | 桌、人物、背景分别生成，透视和接触未锁 | 重新生成适配当前场景的完整构图 |
| 人物走路像平移 | 只有位置 tween，没有步态帧 | 生成统一基线的六帧步态 |
| 少翁/皇帝边走边回头 | 身体朝向、视线轴和路径冲突 | 选侧面机位，锁头肩胸朝向移动方向 |
| 皮影头大身小、拼接不真实 | 拆零件或不同画布比例 | 生成完整影人帧，校准头身和脚底比例 |
| 灯和火焰像两个东西 | 火焰被当成独立贴纸 | 灯体、灯盘、灯芯、火焰一体生成 |
| 回忆宫宴的宫女哭丧 | 角色情绪没有服从叙事时段 | 生成美好回忆用的完整群像，不用悲伤素材硬套 |
| 台词和画面对不上 | 旁白写复杂流程，画面只有一张简单图 | 按每个工艺词拆成操作帧和接触证明 |
| 声音有方言或不像皇帝 | 只看“权威”标签，没筛口音 | 明确筛标准普通话，做 3–5 个试听并保留淘汰记录 |
| 字幕左贴、右边被遮 | 没有安全区和对齐规范 | 默认底部水平居中，抽帧检查边界和前景遮挡 |
| 预览打不开/刷新旧画面 | file URL、服务器、缓存或素材路径问题 | 用项目服务器、绝对资源路径、版本化文件名和渲染抽帧复核 |

## 13. 复盘后的最低交付包

一个可交付的纸片动画项目至少应保留：

- 可编辑的 `story-manifest.json` 与分镜/空间圣经；
- 历史来源与排除清单；
- 身份参考、完整姿势图集、ensemble、整场景多帧和 alpha 成品；
- 每场独立配音、试听候选、实测时长和混音说明；
- proof frame / contact sheet / motion sidecar；
- HyperFrames 检查结果；
- 通过审片的 master、社会化版本和 FFprobe 报告。

## 14. 复盘结论

纸片动画不是“把几张漂亮图片放在一起”。真正的导演工作，是把历史空间、人物关系、材料物理、动作因果、声音归属和时间轴变成同一个可复查的系统。任何一个环节不成立，观众就会看到悬浮的桌子、错误的朝向、顺移的步态、方言的皇帝或与台词不对应的画面。

先证明，再装饰；先适配，再复用；先完整，再拆层。这个顺序比增加素材数量更能提升作品质量。
